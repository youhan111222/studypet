# 高等数学 — 考点地图（100 分 · 120 分钟）

> 目标：2027-03 广东专升本 ｜ 题型：单选 20×2 + 填空 10×3 + 计算 6×5

## 分值重心
- **计算 30 分**：极限、导数、不定/定积分、微分方程、级数 —— 每题 5 分，套路固定，性价比最高
- **填空 30 分**：结论性（极限值、导数、积分值、通解形式）
- **单选 40 分**：概念（连续性/可导/极值/收敛） + 小计算

## 章节地图（对应考纲 12 知识点）
```
1 函数与极限 ──→ 2 连续与间断 ──→ 3 导数与微分 ──→ 4 中值定理与应用
                                                        │
5 不定积分 ←───────────────────────────────────────────┘
6 定积分及其应用（面积/体积）
7 微分方程（一阶/二阶常系数）
8 多元函数微分（偏导/极值）
9 无穷级数（收敛判定/幂级数）
```

## 主线逻辑（一章吃透再下一章）
- 极限是地基：等价无穷小 8 个必须背熟（sin x ~ x, tan x ~ x, 1-cos x ~ x²/2, ln(1+x) ~ x, e^x-1 ~ x...）
- 导数三件套：四则/复合/隐函数；中值定理只需会用（罗尔/拉格朗日）
- 积分与导数互为逆运算：凑微分/换元/分部
- 微分方程 = 会分离变量 + 二阶常系数特征方程
- 级数：正项级数用比较/比值；幂级数求收敛半径 R = 1/ρ

## 高频易错
- 可导 ⇒ 连续，连续 ⇏ 可导（|x| 在 0）
- 驻点不一定是极值点（y=x³）
- ∫1/x dx = ln|x| + C（绝对值别丢）
- 奇函数对称区间积分 = 0
- 二阶常系数齐次：特征根重根时通解 (C1+C2x)e^(rx)
- 隐函数求导：对 x 求导时 y 要乘 y′

## 学习顺序建议
1. 极限 + 连续（3 天）
2. 导数 + 中值定理（3 天）
3. 不定积分 → 定积分（4 天，重点）
4. 微分方程（2 天）
5. 级数 + 多元（3 天）
6. 之后每天 1 道计算综合题保温
