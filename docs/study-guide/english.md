# 英语 — 考点地图（100 分 · 120 分钟）

> 目标：2027-03 广东专升本 ｜ 题型：阅读 15×2 + 匹配 5×2 + 完形 15×2 + 语法填空 10×1.5 + 写作 1×15

## 分值重心
- **阅读 30 分 + 完形 30 分 = 60 分**：词汇量和语感是根本，每天精读 1 篇 + 泛读 1 篇
- **语法填空 15 分**：时态/非谓语/从句/固定搭配 —— 提分最快（规则性最强）
- **写作 15 分**：应用文模板（信函/通知/邮件），背 2-3 个框架即可拿基础分

## 能力地图（对应考纲 15 知识点）
```
词汇 3000（贯穿全程）
├─ 构词法：词根词缀（-tion/-ness/un-/re-）→ 猜词题
├─ 近义词辨析 + 短语动词 → 完形题核心
语法（规则为王）
├─ 时态语态：完成时/进行时/被动 ← 语法填空高频
├─ 非谓语：不定式/动名词/分词 ← 语法填空高频
├─ 从句：定语/名词性/状语 ← 阅读长难句基础
├─ 虚拟/倒装/主谓一致
阅读（练题型）
├─ 主旨要义 → 首尾段 + 转折词
├─ 细节定位 → 题干关键词回原文
├─ 词义推断 → 上下文线索
├─ 判断推理/作者意图 → 态度词
写作：信函/通知/邮件三段式
```

## 高频易错（语法填空 15 分就考这些）
- the number of + 复数名词 → 谓语单数
- be worth doing（主动表被动）
- suggest/essential 后虚拟语气用原形
- not only ... but also；look forward to doing
- by the time + 将来完成时
- 定语从句：reason → why；place → where；人/物 → who/which
- next/last/this 时间词前不加介词

## 学习顺序建议
1. 语法规则扫盲（时态/非谓语/从句，2 周）
2. 词汇：每天 50 词 + 复习（滚雪球）
3. 阅读每天 2 篇（精读 1 + 泛读 1）
4. 完形专项：上下文线索训练
5. 写作模板：考前 1 个月背框架 + 每周写 1 篇
