# 政治 — 考点地图（100 分 · 120 分钟）

> 目标：2027-03 广东专升本 ｜ 题型：单选 20×1 + 多选 10×2 + 辨析 2×7 + 问答 3×7 + 论述 1×10 + 材料 1×15

## 分值重心
- **材料分析 15 + 论述 10 = 25 分**：原理 + 现实结合，必须背熟马原核心原理 + 习思想表述
- **问答 21 分**：要点型，采点给分（背"要点短语"，如实践四作用：来源/动力/标准/目的）
- **多选 20 分**：易错重灾区（漏选/多选都错），靠精确记忆
- **单选 20 分**：基础概念，送分题

## 章节地图（对应考纲 25 知识点）
```
马克思主义哲学原理（约 30 分）
├─ 唯物论：物质/意识/实践
├─ 辩证法：联系/发展/三大规律/五对范畴 ← 高频
├─ 认识论：实践与认识/真理 ← 高频
├─ 唯物史观：社会存在与意识/人民群众
毛泽东思想（约 20 分）
├─ 新民主主义革命理论（总路线/三大法宝）
├─ 社会主义改造理论（总路线/原则）
├─ 活的灵魂：实事求是/群众路线/独立自主
习近平新时代中国特色社会主义思想（约 50 分）
├─ 新时代主要矛盾 ← 必背
├─ 中国式现代化五个特征 ← 高频
├─ 高质量发展/全过程人民民主
├─ 十四个坚持（第一条：党对一切工作的领导）
└─ 时政结合（百千万工程等广东实践）
```

## 高频易错（多选/辨析重灾区）
- 三大法宝：统一战线/武装斗争/党的建设（土地革命不是法宝）
- 活灵魂 vs 三大法宝别混
- 辨析"真理绝对即无相对"→ 错，绝对相对统一
- 辨析"新民主主义革命是社会主义革命"→ 错，性质是资产阶级民主革命
- 主要矛盾：人民日益增长的美好生活需要 vs 不平衡不充分发展
- 认识的两次飞跃：感性→理性、理性→实践
- 中国式现代化 5 特征（不是 4 个，别漏"人与自然和谐共生"）

## 学习顺序建议
1. 马原哲学（理解为主，2 周）——论述/材料题的原理来源
2. 毛泽东思想（记忆为主，1 周）
3. 习思想（当前重点，2 周）——分值最大且与时政结合
4. 每周：1 道论述 + 1 道材料分析练笔（自评）
5. 时政：考前 3 个月关注广东本地实践案例
