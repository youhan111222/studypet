# 电子技术基础 — 考点地图（200 分 · 150 分钟）

> 目标：2027-03 广东专升本 ｜ 题型：单选 20×3 + 填空 10×4 + 判断 10×2 + 计算 5×16

## 分值重心（先学大头）
- **计算题 80 分**：运放比例运算、共射静态工作点、负反馈类型判断、卡诺图化简、时序电路分析 —— 必须动手算，不能只看
- **单选 60 分**：概念辨析为主（三极管状态、反馈极性、触发器特性表）
- **填空 40 分**：结论性知识点（虚短虚断、β 定义、78xx 系列、555 应用）

## 章节地图（对应考纲 17 章）
```
模拟部分（约 55% 分值）
├─ 1 半导体二极管 → 单向导电、稳压管、整流滤波
├─ 2 BJT 放大电路 → 三种状态、静态工作点、三种组态特性 ← 高频
├─ 3 场效应管 → 与 BJT 对比记忆（电压控制 vs 电流控制）
├─ 4 集成运放 → 虚短虚断、比例/加减/积分电路 ← 高频
├─ 5 反馈 → 四种组态判断 + 对性能影响 ← 高频
├─ 6 功率放大 → 甲乙类、交越失真、效率
├─ 7 直流稳压 → 整流滤波稳压、78xx
└─ 8 信号产生 → 振荡条件、555 应用
数字部分（约 45% 分值）
├─ 9 逻辑代数 → 公式/摩根定律/卡诺图化简 ← 高频
├─ 10 组合逻辑 → 编码译码、加法器、多路选择器
├─ 11 触发器 → JK/D/T 特性表 ← 高频
└─ 12 时序电路 → 计数器/寄存器分析 ← 高频
```

## 学习顺序建议
1. 二极管/BJT/运放三大器件（2-3 天）
2. 负反馈（承上启下，必考）
3. 数电逻辑代数 + 卡诺图
4. 触发器 + 计数器（时序是数电难点）
5. 计算题专项：每天 2 道（运放 + 静态工作点轮换）

## 高频易错
- 共射反相、共集同相且增益≈1
- 虚短仅深度负反馈成立；虚断恒成立
- 负反馈以增益换稳定：增益↓、带宽↑、失真↓
- 编码器 vs 译码器方向相反
- 时序电路输出 = f(当前输入, 原状态)
- 乙类效率最高但有交越失真 → 实际用甲乙类
